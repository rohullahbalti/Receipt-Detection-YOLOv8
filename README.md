# Receipt-Detection-YOLOv8
Receipt Detection using YOLOv8
🔹 Project Overview

This project demonstrates Receipt Detection using a fine-tuned YOLOv5 model. The model has been trained on a custom dataset to detect receipts in images.

The workflow includes:

Preparing a custom dataset.

Training YOLOv5 on the dataset.

Saving the best model weights.

Testing the model on sample images.

Displaying the detection results with bounding boxes.
